### 🎓 PlaceHub — Student Placement Portal
> A full-stack placement portal with **3 user roles** — Student, Recruiter & Admin

- 🔐 JWT Authentication + Role-based access
- 📋 Admin approves recruiters & job posts
- 💼 Students browse & apply for jobs
- 📊 Real-time dashboards for all roles
- 🗄️ SQLite + Sequelize ORM

**Tech:** `React` `Node.js` `Express` `SQLite` `JWT` `Sequelize`
